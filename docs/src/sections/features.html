02 / FEATURES

Made for playing, not just browsing.

Keeping fakes out is the main job. The rest makes it pleasant to use every day.

▣

Feels like the original

Familiar GoldSrc tabs and olive green chrome, with country flags beside server names. Flags use an approximate offline IP country lookup. Right-click to filter by country or continent.

☰

See who's playing

Open a server's info to see its players with their scores and time on the server, so you can tell a busy match from a quiet one before you join.

⌕

Filters and search

Independent Name and Game filters accept exclusions such as !www,!discord,!VIP. Filter by map, ping, anti-cheat, bots (including ones a bot plugin reports as players), full or empty servers and passwords. The list updates as you type.

★

Favorites and history

Right-click a server to keep it in Favorites. Every server you join lands in History, so last night's game is easy to find again.

↵

Quick to join

Move with the arrow keys, then press Enter or double-click. Steam starts the game and connects you.

↻

Custom portable build

Extract the Windows x64 ZIP and run the EXE. Upstream updates are disabled to preserve these customizations.
